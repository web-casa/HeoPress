Release notes 4.2

Version 4.2 of the Example toolkit improves start-up time by about thirty percent on typical projects and reduces memory use when many plugins are installed.

The configuration loader now reports the file and line of every invalid option. See the configuration guide and the migration notes for details.

Deprecated: the legacy command-line flags announced in 3.0 are removed. Scripts that still use them should switch to the long option names described in the reference.

Thanks to everyone who reported issues and tested the release candidates over the past two months.
