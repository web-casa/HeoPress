# 公开发布记录

HeoPress 公开仓库的版本与标签。每个版本在公开仓库是一个提交，带同名的附注标签。

本表只记公开信息：版本、标签、日期与说明。发布某个版本前，先在本表加一行并提交，发布流水线只发布本表列出的版本。

| 版本 | 标签 | 日期 | 说明 |
|---|---|---|---|
| 1.0.0 | `v1.0.0` | 2026-11-08 | 首个正式版本：站群 CMS、AI 原生内容流程、行级隔离默认开启（P14）。 |
| 1.2.0 | `v1.2.0` | 2026-11-11 | v1.1 与 v1.2 的能力：WordPress 导入、翻译待办、简报式改写、时效标记与复核提醒、官方简报插件（分节 / 草稿 / 路由 / feed）、Markdown 内容协商、翻译服务扩展点与 DeepL 插件、插件密钥存储、静态站边缘协商；另有对外贡献入口（CONTRIBUTING、行为准则）。 |
| 1.2.1 | `v1.2.1` | 2026-11-11 | 补丁：CLI/CI 层面把 CLA 变成机器检查（`CLA signed`，签名记录在 `.github/cla-signatures.json`），并记录 v1.2.0 的发布对应关系。产品行为无变化。 |
| 1.3.0 | `v1.3.0` | 2026-11-12 | 新增：Netlify 的 Markdown 内容协商（Edge Function，矩阵由「不支持」改为「支持」）；静态目标协商四家齐全。修复：`theme-pool` 慢启动测试的余量不足导致 CI 偶发超时。 |
| 1.3.1 | `v1.3.1` | 2026-11-12 | 文档与内部工具：修正 v1.3.0 里 Netlify 协商的能力声明（`yes` → `degraded`，因为本部署路径不发送 `edge_functions`），补 `docs/en/publishing/` 两篇英文文档，中英一致性门禁接入 `check:all`。产品行为无变化。 |
| 1.4.0 | `v1.4.0` | 2026-11-13 | 新增：双模型翻译（起草→机械门禁→复核修正，不依赖 MT 厂商）；翻译任务队列（持久化、延后不消耗重试、崩溃恢复不重复付费）；站点术语表管理与 `forbidden`/`do-not-translate` 规则真正生效。修复：术语表规则在边界被丢弃导致禁用译法可通过校验。 |
| 1.5.0 | `v1.5.0` | 2026-11-14 | 新增：站点静态目录挂载（存档页与新文章同源共存，系统路径与条目永不遮蔽）；官方纠错插件（公开纠错表单 → 审核 → 文章上的更正记录与结构化数据）。修复：镜像运行时验收失败时不再只写「重启了」，改为带退出码、OOM 与日志；插件打包验收覆盖每个官方插件（此前只覆盖术语表）。 |
