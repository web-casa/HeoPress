# ai/flow-authoring Specification

## Purpose
允许 Agent 根据自然语言需求起草内容流程定义，但流程必须经过校验，并由人类在后台按实例审批模式审批后才能启用，防止 Agent 自行扩大自动化范围。

## Requirements

### Requirement: 起草与审批分离
Agent SHALL 能提交流程定义草稿，草稿只能引用已注册的操作类型。草稿 MUST 经过校验，并由具备权限的人类用户在后台审批后才能启用；Agent 渠道 MUST NOT 能审批。审批规则遵循实例审批模式：单人模式下起草用户须完成二次验证，团队模式下审批人须与起草用户不同。

#### Scenario: 引用未注册操作
- **WHEN** Agent 提交的流程引用了不存在的操作类型
- **THEN** 草稿校验失败，并指出未知的操作类型

#### Scenario: 团队模式自行审批
- **WHEN** 团队模式下，起草用户尝试审批自己通过 Agent 提交的流程草稿
- **THEN** 返回 403，流程保持未启用

#### Scenario: 单人模式未完成二次验证
- **WHEN** 单人模式下，起草用户未完成二次验证就审批流程草稿
- **THEN** 审批被拒绝，流程保持未启用
