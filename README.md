# HeoPress

**AI-native, open-source CMS for running a network of websites.**
**面向多站点运营的 AI 原生开源 CMS。**

> Status: in early development. No code has been released yet.
> 状态：早期开发中，尚未发布代码。

## What it aims to do / 目标

- Manage many independent domains from one installation, with per-site themes and settings.
  一个实例管理多个独立域名站点，每站独立主题与设置。
- Multilingual sites, including translations that live on different domains.
  多语言站点，支持跨域名的译文关联。
- AI-assisted content workflows with quality gates and human review, plus auditable provenance.
  带质量门禁与人工审核的 AI 辅助内容流程，全程可追溯。
- Solid SEO and GEO output: canonical, hreflang, structured data, sitemaps, llms.txt, Markdown copies.
  完整的 SEO / GEO 输出。
- Works with the AI agents you already use, through MCP with per-user, per-site authorization.
  通过 MCP 接入你已有的 AI Agent，按用户、按站点授权。
- Self-hosted on a VPS with PostgreSQL.
  基于 PostgreSQL 的 VPS 自托管。
