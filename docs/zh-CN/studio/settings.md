# 设置

设置模块的二级面板分三组，只列出当前用户有权进入的分区：

| 组 | 分区 | 谁能看到 |
|---|---|---|
| 工作区 | 常规、外观、成员与权限 | 外观所有人；其余仅站点管理员 |
| 系统 | API 与密钥、通知、许可证 | 站点管理员 |
| 高级 | 角色与策略、数据模型、自动化、品牌与站点地址、全部账户（经典）、快捷键、编辑配置、存储、模型、上传、团队、Git 集成、Webhook、Change Feed、部署、邮件、扩展、市场、开发者类型、Agent、物化、安全、加密、更新 | 站点管理员 |

没有站点管理权限的成员打开 `/settings` 会进入“外观”；直接打开管理员分区的地址时，页面说明“仅站点管理员”。

## 外观

主题（亮色 / 暗色 / 跟随系统，带缩略预览）、信息密度（舒适 / 紧凑）与界面语言，修改立即生效并保存到账户。“减少动态效果”跟随操作系统设置。

## 常规

站点名称、默认语言（站点语言之一）与时区（IANA 名称，例如 `Asia/Shanghai`）。字段无效时在旁说明，保存按钮写明“先修正 N 处错误”。
后台入口路径只读显示：它在安装服务器时设定，不在此修改。修改站点名称与默认语言只限站点管理员（服务端同样检查）。

## 成员与权限

- 列表显示名字、邮箱、角色、账户状态（已激活 / 尚未接受邀请 / 已停用）与最近活跃时间。
- 邀请：输入一个或多个邮箱（逗号、分号、空格或换行分隔），选择角色后发送；每个邮箱单独显示结果，已是成员的显示“已是成员”且角色不变。
- 修改角色：直接在列表中选择。移出成员（包括尚未接受邀请的）前会确认，并说明对方立即失去本站访问权。
- 站点至少保留一名可用的管理员；会违反这一点的修改被服务端拒绝，页面显示原因。
- 账户的启用与停用只属于实例的引导管理员，站点管理员只调整本站的成员关系与角色。
- 角色、策略与团队页从页面右上角进入（位于“高级”）。

## API 与密钥

列表显示名称、末 4 位、权限范围（附加的角色与策略）、创建时间与最近使用时间；超过 90 天未使用的密钥标出“建议吊销”。
新建密钥后完整密钥**只显示一次**，关闭后只能看到末 4 位（2026-10 之前创建的旧密钥只显示前缀）。吊销前会确认：使用该密钥的调用会立即失败。
附加角色或策略在“高级 › 角色与策略 › API 密钥”中进行。

## 许可证

显示版本、构建与许可证（AGPL-3.0-only，附插件与主题例外），可打开许可证全文、第三方声明与 NOTICE；商业授权的说明见同页。
