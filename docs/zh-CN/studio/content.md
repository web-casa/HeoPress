# 内容与审稿工作台

HeoPress P07a 任务 5.1–5.6（规格 `studio/review-workspace`）。在 Studio 一级导航“内容”中打开；旧地址 `/content/<集合>/reviews` 会跳转到这里的“待审核”视图。

## 视图与筛选

| 视图 | 内容 |
|---|---|
| 收件箱 | 等待你处理的：你有审核权限的集合中的待审稿件，以及被退回给你的稿件 |
| 我的稿件 | 你创建的稿件 |
| 待审核 | 所有正在等待审核的稿件 |
| 定时发布 | 尚未发布、设定了未来发布时间的稿件 |
| 已发布、草稿 | 按状态 |

- 只列出你有权读取的集合中的稿件（含行级规则）；可按集合、作者、语言筛选，按标题搜索。
- 视图、筛选、搜索与选中的稿件都写入页面地址，刷新或分享地址后保持一致。
- “集合”入口仍可按集合浏览全部条目（原内容列表）。

## 审核权限

- 批准与退回需要该集合的 `review` 权限（站点管理员自动拥有），并且只能由人在 Studio 中操作：API Key、Agent 与 MCP 工具一律被拒绝，提交审核仍可由 Agent 发起。
- 升级后其他角色默认没有 `review`，需要管理员在“设置 › 高级 › 角色与策略”中授予（见 `docs/en/release/upgrade-notes.md`）。
- 集合开启“要求由他人审核”时，起草者不能批准自己的稿件。
- 没有审核权限时，详情区不显示批准与退回，并说明“需要管理员或已获得审核权限的角色审核”。

## 详情区

- 属性（状态、作者、篇幅、计划发布时间）、正文预览、发布前检查与处理记录（提交、批准、退回及原因）。
- **发布前检查**只是提示，是否能发布仍按站点的发布规则：标题与描述长度、收录设置、正文中指向本站的链接是否指向已发布页面（在数据库中解析，不访问外部地址）、
  外部链接（一律“未检查”）、图片替代文本；结构化数据在发布时生成，已发布条目的问题见站点审计。你无权读取的字段显示“无权查看”。
- **批准**；**退回**必须填写原因，原因记入处理记录，作者可见；操作后自动选中下一篇。
- 已批准的稿件可**发布**或**按计划发布**（需要更新权限）；**批准并发布**先批准再发布，发布失败时稿件停在已批准，显示失败原因与“重试发布”。

## 键盘

- `J` / `K` 在列表中切换稿件；`⌘↵`（Windows / Linux 为 `Ctrl+Enter`）批准当前稿件。有未通过的检查时，第一次按下只显示未通过项与“仍然批准”，再按一次（或回车）才批准。
- `G` 然后 `C` 进入内容模块；`?` 查看全部快捷键。

## 文章编辑器

文章类集合（站点预设的 `articles`，以及在“数据模型 › 集合”中勾选“按文章编辑”的集合）的条目在三栏编辑器中打开；页面、分类等其他集合仍用通用表单。

- **顶栏**：返回、集合与标题、状态、保存状态（未保存 / 保存中 / 已保存时间 / 保存失败与重试）、同时在场的协作者、预览、保存、提交审核（启用审核流程时）或发布。
- **大纲**：由正文的 H2 / H3 生成，点击跳到对应标题，当前标题高亮。窗口变窄时先隐藏大纲，再把检查器移到正文下方。
- **检查器**：SEO（搜索结果预览、描述长度提示，偏短只提示不阻止保存）、收录与引用（结构化数据、链接、图片检查与 Markdown 副本地址）、属性（作者、最近审核人与其余字段）。检查结果对应最近一次保存。
- **保存**：基于打开时的版本保存；他人先保存时显示对方改动的字段，可“保留双方修改”或“使用对方版本”，不会静默覆盖。有未保存的修改时离开页面或切换站点会先确认。
- **地址变更**：已发布文章修改 slug / 地址时，与通用表单一样先列出可能受影响的页面。
- **全部字段与操作**：删除、下线、翻译组与修订记录在通用表单中（顶栏“全部字段与操作”，地址带 `?form=full`）。
