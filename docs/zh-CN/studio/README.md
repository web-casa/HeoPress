# Studio 使用说明

Studio 是 HeoPress 的管理后台（ADR-0019，Carbon 设计）。界面分为左侧模块栏、模块二级面板与主区域；窄屏时模块栏与面板收进顶栏的抽屉。
界面语言为简体中文与 English（设置 › 外观），主题与信息密度跟随账户保存。

## 模块

| 模块 | 地址 | 快捷键 | 说明 |
|---|---|---|---|
| 概览 | `/overview` | `G` `O` | 当前站点或全部站点（只读汇总）的待处理事项、关键指标与最近动态 |
| 内容 | `/content` | `G` `C` | 审稿工作台、文章编辑器、集合、媒体与翻译 — 见 [内容](content.md) |
| 站点 | `/sites` | `G` `S` | 站群拓扑、站点列表与域名 |
| SEO / GEO | `/seo` | `G` `E` | 搜索结果外观、AI 爬虫策略、机器可读输出、规范域名、站点身份、根文件、重定向 — 见 [SEO / GEO](seo-geo.md) |
| AI 流量 | `/ai-traffic` | `G` `A` | AI 爬虫访问与 AI 引荐 — 见 [AI 流量](ai-traffic.md) |
| 审计 | `/audit` | `G` `U` | 站点审计问题的处置与站内链接 — 见 [审计](audit.md) |
| 日志与监控 | `/monitoring` | `G` `L` | 服务状态与只读事件流（仅站点管理员） — 见 [日志与监控](monitoring.md) |
| 设置 | `/settings` | `G` `,` | 常规、外观、成员与权限、API 与密钥、许可证、高级 — 见 [设置](settings.md) |

所有地址都在服务器的私有后台入口路径之下（例如 `/<入口路径>/overview`）。旧版 Studio 的地址会自动跳转到新位置并保留查询参数。

## 通用操作

- `⌘K` / `Ctrl K`：搜索并跳转到任意视图；`?`：快捷键一览。
- 列表中 `J` / `K` 选择下一项 / 上一项。
- 有未保存的修改时，离开页面、切换分区或切换站点前会先确认。
- 没有权限的分区不出现在面板中；直接打开其地址时页面说明原因。
- 系统设置“减少动态效果”时，界面不播放动画。
