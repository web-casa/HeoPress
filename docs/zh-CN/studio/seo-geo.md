# SEO / GEO

SEO / GEO 模块集中当前站点与搜索引擎、AI 助手相关的设置。每个分区左侧是说明，右侧是表单；地址反映当前分区，可直接分享。

| 分区 | 地址 | 内容 |
|---|---|---|
| 搜索结果外观 | `/seo` | 标题模板、描述模板（占位符 `{title}`、`{site}`、`{description}`），是否允许收录本站；右侧实时预览一篇已发布文章在搜索结果中的样子 |
| AI 爬虫策略 | `/seo/crawlers` | 按用途（AI 搜索、按用户提问读取、模型训练）允许或阻止，预设“全部允许 / 仅搜索与引用 / 全部阻止”，Content-Signal；预览说明对 AI 引用与训练的含义 |
| 机器可读输出 | `/seo/machine` | llms.txt、Markdown 副本、订阅源、IndexNow、新闻站点地图；左侧显示结构化数据检查 |
| 规范域名 | `/seo/canonical` | 本站已启用的域名之一；其他域名重定向到它 |
| 站点身份 | `/seo/identity` | 本站代表的组织、个人或本地商家 |
| 根文件 | `/seo/root-files` | ads.txt、验证文件等 |
| 重定向 | `/seo/redirects` | 列表、删除；导入 CSV 或 Redirection / Yoast / Rank Math 导出，先“检查”再“导入” |
| 内容规则 | `/seo/content` | 赞助披露、跨站翻译、站点预设（原“内容设置”页） |

## 权限

站点成员可以查看每个分区；修改只限站点管理员。没有管理权限时控件不可用，左侧说明“需要站点管理员权限”。

## 预览与保存

- 预览只在页面中计算，**不会保存**：改为“全部阻止”后 robots.txt 不变，直到点击保存。
- 有未保存的修改时，页面底部显示修改数量、“放弃”与“保存”；离开页面、切换分区或切换站点前会先确认。
- 字段有错误时（如标题模板缺少 `{title}`、规范域名未绑定到本站），错误显示在字段旁，保存按钮写明“先修正 N 处错误”。
- 保存成功后：页面头部、robots.txt、站点地图与 llms.txt 从下一次请求起按新设置生成；站点前有 CDN 时以缓存过期为准。
- 两人同时修改时，后保存的一方会收到冲突提示，需要放弃后重新修改，不会静默覆盖。
